# 🍽️ Recipes CRUD API

A RESTful API for managing recipes built with Node.js, Express.js, and MongoDB using Mongoose. This project follows the MVC architecture and supports full CRUD operations with proper validation and error handling.

## 🚀 Features

- Create a new recipe
- Get all recipes
- Get a recipe by ID
- Update a recipe
- Delete a recipe
- MVC Architecture
- MongoDB integration with Mongoose
- Error handling & validation
- Tested using Postman

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB (Mongoose)
- Postman

## 🌍 Deployment

Push project to GitHub
Deploy using Render
Add environment variables in Render dashboard
